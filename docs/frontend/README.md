# フロントエンドドキュメント一覧

買い物リストアプリケーションのフロントエンド関連ドキュメントのナビゲーションガイドです。

## 📚 ドキュメント構成

### 開発者向けガイド

#### 1. [フロントエンド開発ガイド](../../frontend/README.md)
**対象**: 新規開発者、環境セットアップ

**内容**:
- 技術スタック（React, Vite, Tailwind CSS, LIFF）
- 開発環境のセットアップ手順
- 環境変数の設定方法
- ビルドとデプロイの手順
- トラブルシューティング

**こんな時に**:
- プロジェクトに初めて参加する
- 開発環境を構築する
- ビルドエラーを解決する

## 🔄 ドキュメント更新ガイドライン

### 更新が必要なケース

1. **新機能の追加**
   - コンポーネント追加 → `components.md` に追記
   - API追加 → `api-client.md` に追記
   - 設計変更 → `architecture.md` を更新

2. **技術スタックの変更**
   - ライブラリ追加・更新 → `README.md` を更新
   - アーキテクチャ変更 → `architecture.md` を更新

3. **バグ修正**
   - 既知の問題 → `README.md` のトラブルシューティングに追記

### 更新手順

1. 該当ドキュメントを特定
2. 変更内容を追記または修正
3. 関連ドキュメントへのリンクを確認
4. コミットメッセージに `docs:` プレフィックスを付与

```bash
git commit -m "docs: コンポーネント追加に伴うドキュメント更新"
```

## ✨ ドキュメントのメンテナンス

このドキュメントは以下の原則に基づいて管理されています：

1. **正確性**: コードと同期した最新の情報を維持
2. **完全性**: 開発に必要なすべての情報をカバー
3. **可読性**: わかりやすい日本語とMarkdown記法
4. **実用性**: 実際の開発作業に役立つ内容

ドキュメントに関する質問や改善提案は、リポジトリのIssueで受け付けています。
